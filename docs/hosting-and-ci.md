# Hosting и CI для SmartNotes

## Что важно понимать
- GitHub Pages и GitHub Actions CI — это разные механизмы.
- Pages отвечает за публикацию статического сайта.
- CI отвечает за автоматические проверки качества кода.

## Текущая модель проекта
- Сайт статический: `html + css + js` без обязательного backend build.
- Публикация через Pages может работать из `main / (root)`.
- Проверки в CI запускаются отдельно и не мешают стандартной публикации из ветки.

## Как включить публикацию сайта
1. Открыть `Settings → Pages`.
2. В `Source` выбрать `Deploy from a branch`.
3. Выбрать `Branch: main` и `Folder: /(root)`.
4. Сохранить настройки.

## Что делает CI в этом репозитории
- `npm test` — запускает стабильностные тесты.
- `npm run check:module-graph` — проверяет, что все `js/**/*.js` файлы достижимы от `index.html`.

CI нужен для защиты от регрессий в коде, даже если сайт публикуется как простой статический Pages-проект.
