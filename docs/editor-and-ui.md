# Редактор и Пользовательский Интерфейс (UI)

Вместо использования готовых библиотек или тяжелых React-редакторов (вроде Slate или ProseMirror), SmartNotes использует собственный кастомный движок редактора (Rich Text Editor).

## Структура редактора (`public/js/editor/`)

Редактор экспортируется глобально как `window.SmartNotesEditor` (см. `core-api.js`). Он состоит из набора независимых модулей:

- **`core-state.js` / `core.js`**: Хранилище текущего состояния (активная заметка, режим редактирования, dirty flag).
- **`input-handlers.js` / `input-engine.js`**: Обработка ввода (включая перехват вставки из буфера обмена, форматирование, ссылки).
- **`core-autosave.js`**: Механизм автосохранения. Отслеживает изменения (`hasSnapshotChanged`) и периодически отправляет диффы в Supabase.
- **`feature-engine.js`**: Агрегирует продуктовые фичи, такие как встроенный калькулятор. Математические выражения могут вычисляться прямо в редакторе (логика `evaluateExpression` ищет выражение рядом с кареткой).

## Слой рисования (Drawing Layer)

В редактор встроен механизм рисования поверх заметки:
- **Файлы:** `drawing.js`, `drawing-engine.js`, `drawing-loader.js`.
- **Инструменты:** Карандаш (pen), маркер (marker), ластик (eraser).
- **Как это работает:** Слой использует Canvas API. При рисовании сохраняется история штрихов (с поддержкой undo/redo в `core-engine.js`). Рисунок сериализуется в Data URL и сохраняется в свойстве `pageDrawings` заметки (с отслеживанием версий через `pageDrawingsRevision`).

## Темизация и CSS Переменные

Интерфейс управляется исключительно через CSS переменные. Подход "Zero JS styling" в рантайме.

- **`public/css/base.css`**: Содержит основную палитру и токены (шрифты Inter и JetBrains Mono, отступы, z-index'ы). Все базовые цвета (например, `--bg`, `--surface`, `--text`) определены здесь.
- **`public/css/components.css`**: Стили конкретных UI компонентов (кнопки, диалоги, модалки).
- **`public/css/editor.css`**: Стили области редактирования (типографика контента, выделения, списки).
- **Динамическая смена тем (`public/js/theme.js`)**:
  Пользовательские настройки цвета обновляют значения CSS переменных в `:root` (или на элементе `body`). Дополнительно реализована поддержка облачных URL-фонов (обработка изображений) с кэшированием и локальных изображений (через `ImageHelper.optimizeImageDataUrl`).

## Работа с медиа

Вставка медиа обрабатывается в `core-media.js` и `media-placement.js`. Изображения оптимизируются на клиенте с помощью `public/js/core/image-helper.js` (ресайз и сжатие в JPEG через Canvas API) перед загрузкой в хранилище или сохранением в виде Data URL.
