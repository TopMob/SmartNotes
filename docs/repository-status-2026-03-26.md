# SmartNotes — статус готовности репозитория

- Обновлена компоновка редактора для более стабильной рабочей области и кликов в контентной зоне.
- Централизована backend-конфигурация и восстановлен базовый тестовый контур `npm test`.

## Текущая модульная структура
- `js/core/` — инфраструктура приложения, auth/bootstrap/runtime.
- `js/ui/` — слой представления, события, layout, модальные окна.
- `js/notes/` — домен заметок, репозитории, сервисы, presenter-слой.
- `js/editor/` — редактор, команды форматирования, медиа, рисование, autosave.
- `docs/` — статус, backlog, продуктовые и технические документы.

## Операционная информация
- Frontend-репозиторий: текущий.
- Backend-репозиторий: https://github.com/TopMob/backendfornmartnotes
- Production backend URL: https://backendfornmartnotes.vercel.app/
- Runtime override backend URL:
  - `window.__SMARTNOTES_BACKEND_URL__`
  - `localStorage['smartnotes.backendBaseUrl']`
