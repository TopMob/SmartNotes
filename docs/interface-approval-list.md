# Список идей на утверждение

## Интерфейс фильтров
- Переключатель «Показывать блок Сохранённые фильтры».
- Переключатель «Показывать блок Сортировка».
- Переключатель «Показывать блок Теги».
- Переключатель «Показывать блок Период обновления».
- Переключатель «Показывать блок Папки».
- Переключатель «Показывать кнопку Фильтры в шапке».

## Поведение корзины
- Переключатель «Показывать кнопку Очистить корзину только в разделе Корзина».

## Пагинация и загрузка
- Переключатель «Показывать кнопку Загрузить ещё».
- Настройка «Количество заметок на странице» с применением сразу после сохранения.

## Экспорт и резервные копии
- Явная подпись статуса «Последняя ручная копия: дата/время».
- Выбор папки перед экспортом папки.
- Выбор папки перед резервной копией папки.

## Единый UX длительных операций
- Общий оверлей загрузки для импорта, экспорта, резервного копирования и загрузки изображений.
- Единые статусы начала/окончания операции без дублирования логики по модулям.

## Синхронизация настроек
- Синхронизация всех новых интерфейсных переключателей между устройствами через user settings.

## Порядок реализации
1. Интерфейс фильтров.
2. Корзина и пагинация.
3. Экспорт/резервные копии.
4. Финальная синхронизация и проверка UX.
