# AI Интеграция (AI Engine)

SmartNotes включает продвинутую систему обработки заметок через нейросети. Вся логика инкапсулирована в `app/api/analyze/`.

## Архитектура API

Конечная точка для AI аналитики — это POST запрос на `app/api/analyze/route.js`.
Он требует передачи специального секрета в заголовке `x-secret` (сравнивается с переменной окружения `API_SECRET`).

### Основной флоу обработки:
1. Вызов инициируется клиентом вручную или через cron/batch-процесс.
2. Сервер извлекает параметр `uid` (или перебирает всех пользователей базы, если передан параметр `reindexAll`).
3. Загружается список заметок пользователя, у которых нет метки `analyzed = true`.
4. Текст заметки извлекается, очищается от HTML-тегов, и если он укладывается в лимиты (`NOTE_TEXT_LIMIT`, по умолчанию разбивается на чанки), передаётся провайдеру для анализа.

## Провайдеры

Система поддерживает множество провайдеров (`app/api/analyze/providers/`), которые конфигурируются через переменную `ANALYZE_PROVIDER`:
- `yandex`
- `chatgpt`
- `deepseek`
- `codexsale`
- `gemini`
- `claude`
- `ollama` (Поддерживается запуск локального моста)

Файл `app/api/analyze/core/processor.js` (совместно с файлами провайдеров, например `prompt.js` и `schema.js`) формирует структурированный JSON ответ.

## Особенности обработки

- **Версионирование промптов (`PROMPT_VERSION`)**:
  При изменении версии промпта, база понимает, что заметки были проанализированы устаревшей схемой, и может переиндексировать их заново при вызове с параметром `reindexAll`.
- **Классификация и Мемоизация токенов**:
  Ответ от LLM парсится на конкретные поля (теги, краткое описание, скрытые теги для поиска). Результат напрямую записывается в поля заметки, что экономит токены при повторных вызовах (заметка помечается как `analyzed = true`).
- **Схема ответа (`schema.js`)**:
  Провайдеры используют строгую JSON схему (или JSON mode) для получения структурированных данных. Ожидается, что ответ содержит метаданные о заметке: категория, ключевые слова и флаги (например, является ли заметка черновиком или списком задач).
