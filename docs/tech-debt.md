# Технический долг и Легаси-код

В процессе анализа текущей кодовой базы были выявлены следующие проблемы, требующие внимания и рефакторинга.

## 1. Отсутствие строгой типизации на фронтенде
Весь фронтенд движок (`public/js/*`) написан на чистом Vanilla JS (ES Modules) без использования TypeScript (или JSDoc типов), хотя бэкенд (`app/api/*` и `lib/supabase/*`) частично использует TypeScript. Это затрудняет поддержку и расширение редактора. В файлах вроде `core-api.js` и `load-app.js` сложные структуры состояний передаются без валидации структуры.

## 2. Глобальное состояние (Global State Pollution)
В проекте активно используются глобальные переменные (`window.SmartNotesEditor`, `window.Calculator`, `globalThis.auth`). Паттерн `StateStore` (в `load-app.js`) реализован как кастомный подписчик, но из-за глобального доступа существует риск неконтролируемых мутаций состояния.

## 3. Обработка ошибок синхронизации
В `load-app.js` метод `isNonCriticalSyncError` прячет часть ошибок, таких как `permission-denied` или `not-found`, выводя их только в консоль:
```javascript
const isNonCriticalSyncError = (error) => {
    const errorCode = String(error?.code || "")
    return errorCode === "permission-denied" || ...
}
```
Это может приводить к скрытым багам, когда у пользователя отваливаются права RLS, а UI не реагирует должным образом (не показывает "Запрещено").

## 4. Кастомная реализация "Реактивности"
Функция `createStateRenderingController` (в `load-app.js`) пытается эмулировать React-подобный жизненный цикл (diffing предыдущего и следующего стейта), но вручную проверяет каждое поле (`configChanged`, `languageChanged`, `folderUiDependenciesChanged`). При добавлении новых полей в `StateStore` эта портянка условий будет бесконтрольно расти, что является бутылочным горлышком.

## 5. Легаси архитектура файлов
- В проекте есть скрипт проверки модульных связей (`scripts/check-unconnected-modules.mjs`), что указывает на исторические проблемы с мертвым кодом.
- `public/js/` сильно раздут (например, `load-ui-core.js` занимает почти 180КБ неминифицированного кода). Необходимо разделить этот файл на более мелкие ES модули.

## 6. Жёстко зашитые значения (Hardcoded Values)
- В `ImageHelper` (`public/js/core/image-helper.js`) зашиты значения `maxDimension: 1600` и `quality: 0.82`. Это должно конфигурироваться глобально в настройках приложения.
- В API роуте AI (`app/api/analyze/route.js`) обработка `reindexAll` вручную парсит строковые значения `true`, `1`, `yes`, что лучше делать через библиотеку валидации (Zod/Joi).

## 7. TODOs
В проекте обнаружены TODO комментарии (в `.git/hooks`), но в самой бизнес-логике TODO часто отсутствуют там, где они явно нужны (например, в обработке fallback сценариев авторизации и обрывов сети в `load-app.js`).
